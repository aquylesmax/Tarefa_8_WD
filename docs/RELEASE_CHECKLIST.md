# Checklist de release

## Antes de publicar
- [ ] Revisar as alteracoes no HTML, CSS e JavaScript.
- [ ] Testar a pagina em larguras diferentes.
- [ ] Conferir links, formulario, filtros e tema.
- [ ] Verificar o console do navegador.
- [ ] Conferir README e documentacao.
- [ ] Confirmar que nao ha dados pessoais ou segredos nos arquivos.

## Depois de publicar
- [ ] Conferir a branch `main` no GitHub.
- [ ] Abrir a pagina publicada, caso o GitHub Pages esteja habilitado.
- [ ] Testar a pagina 404.
- [ ] Registrar a versao e as alteracoes realizadas.
