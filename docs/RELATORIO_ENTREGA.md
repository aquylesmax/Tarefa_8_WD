# Relatório de entrega — NexTech / Atividade de Web Design

## Identificação do trabalho
**Projeto:** NexTech — site institucional demonstrativo
**Disciplina:** Web Design
**Tecnologias:** HTML5, CSS3 e JavaScript puro
**Repositório de referência:** https://github.com/Agudinho/Atividade-6-Web-Design
**Repositório de entrega:** preencher com a URL do repositório criado pelo estudante.

## Objetivo
Construir um site institucional com estrutura HTML semântica, estilo responsivo e
interações implementadas em arquivo JavaScript externo. O projeto busca demonstrar
manipulação do DOM, eventos, validação de formulários, acessibilidade e organização
do código-fonte.

## Arquivos principais
- `index.html`: estrutura do site e conteúdo.
- `style.css`: design visual, estados dos componentes e media queries.
- `script.js`: interações e validações.
- `README.md`: descrição das funcionalidades e instruções de teste.

## Funcionalidades demonstradas
1. Menu móvel acessível.
2. Tema claro/escuro com persistência local.
3. Filtro de cartões por categoria.
4. Acordeão de perguntas frequentes.
5. Validação de nome, e-mail e mensagem.
6. Contador de caracteres.
7. Pré-preenchimento de assunto.
8. Botão de retorno ao topo.
9. Atualização automática do ano.
10. Navegação ativa por seção.
11. Efeitos de entrada com respeito a movimento reduzido.
12. Anúncios acessíveis de estado.

## Plano de testes
1. Abrir `index.html` no navegador.
2. Testar os filtros de serviços.
3. Alternar tema, atualizar a página e confirmar persistência.
4. Abrir e fechar perguntas frequentes com mouse e teclado.
5. Enviar o formulário vazio e verificar mensagens de erro.
6. Enviar formulário com dados de teste e consentimento marcado.
7. Testar menu e layout com largura móvel.
8. Testar navegação por teclado.
9. Verificar a ausência de erros no console.
10. Conferir os arquivos no GitHub depois da publicação.
