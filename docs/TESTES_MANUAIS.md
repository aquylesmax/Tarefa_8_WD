# Roteiro de testes manuais — NexTech

## Navegacao
- [ ] Todos os links do menu levam a secoes existentes.
- [ ] O menu mobile abre e fecha corretamente.
- [ ] A tecla Escape fecha o menu quando aplicavel.
- [ ] O link para pular ao conteudo funciona.

## Aparencia
- [ ] Conferir em desktop, tablet e celular.
- [ ] Alternar tema claro e escuro.
- [ ] Atualizar a pagina e verificar a preferencia de tema.
- [ ] Verificar se nao existe rolagem horizontal em telas estreitas.

## Interacoes
- [ ] Testar cada filtro de servicos.
- [ ] Abrir e fechar perguntas frequentes.
- [ ] Enviar o formulario vazio e observar as mensagens.
- [ ] Testar o formulario com dados validos.
- [ ] Conferir o contador de caracteres.
- [ ] Testar o botao voltar ao topo.

## Acessibilidade e compatibilidade
- [ ] Navegar usando Tab, Shift+Tab, Enter e Espaco.
- [ ] Conferir o foco visivel.
- [ ] Testar a preferencia de movimento reduzido.
- [ ] Conferir erros no console do navegador.

## Publicacao
- [ ] Abrir o site publicado.
- [ ] Conferir a pagina 404.
- [ ] Confirmar que os arquivos publicados correspondem ao repositorio.
- [ ] Registrar capturas reais para a entrega.
